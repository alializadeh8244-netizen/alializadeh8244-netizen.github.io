TRUE VECTOR PRODUCTION NOTES

The SVG in this package is path-based: the artwork is represented by SVG <path> elements rather than an embedded PNG image.

Because the source artwork was raster/generative, the vector file is a reconstructed approximation. Very fine textile texture has been simplified during vectorization to keep the file usable and editable.

Recommended final QA before commercial listing:
1. Open the SVG in Illustrator, Inkscape or Affinity Designer.
2. Zoom to 400–800% and inspect small motifs.
3. Delete any unwanted tiny artifacts.
4. Save an Adobe Illustrator AI copy if the marketplace requires AI.
5. Keep the PNG/JPG preview separate from the vector download.
